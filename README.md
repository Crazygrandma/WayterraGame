# Wayterra

Wayterra game implementation build with SDL3

---

## Downloads & running (for the person who received the game)

You only need the **`Wayterra.exe`** file — it comes as a zip, and there is
nothing to install.

1. **Extract the zip.** Right-click it → *Extract all...* → open the extracted folder.
   (Don't run the game from inside the zip window — extract first.)
2. Double-click **`Wayterra.exe`**.
3. If a blue banner appears — *"Windows protected your PC"* — that is normal
   for games without a paid code-signing certificate. Click
   **More info → Run anyway**. You only need to do this once.
4. Done — the game opens and runs.

### Requirements

- Windows 10 or 11, any normal PC/laptop
- Nothing to install, no admin rights needed

### Troubleshooting

| Problem | Fix |
|---|---|
| "Run anyway" button not shown | The exe is still inside the zip — extract first, then double-click |
| Zip won't open | Use Windows' built-in *Extract all...*; no extra tool needed |
| Game doesn't start | Make sure it was extracted, not launched from inside the zip; check the file wasn't quarantined by antivirus |
